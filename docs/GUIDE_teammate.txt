ГАЙД ДЛЯ РАДОМИРА: ОБУЧЕНИЕ НЕЙРОСЕТИ ДОЭ НА RTX 3050 (6 ГБ)
Команда MEEFEE TEEM. Капитан - Тихон.

ЧТО ЗА ПРОЕКТ
Нейросеть получает 4 картинки и выдаёт одну фазовую маску ДОЭ 128x128.
Из маски физика Френеля восстанавливает 4 картинки на расстояниях 24,1 / 25,3 / 26,5 / 27,7 мм.
Твоя часть: обучить свою версию сети, следить за обучением и объяснить на защите, как она устроена.
Главное обучение идёт ночью у Тихона (RTX 5060). Утром сравним обе модели и возьмём лучшую.

ШАГ 1. ДРАЙВЕР NVIDIA
Win+R -> cmd -> Enter:
    nvidia-smi
Справа вверху должно быть "CUDA Version: 12.8" или больше.
Если меньше или команда не найдена - обнови драйвер (NVIDIA App или nvidia.com) и перезагрузи ПК.

ШАГ 2. PYTHON 3.12
    py install 3.12
    py -3.12 --version
Должно быть Python 3.12.x.
Если "py install" не работает - скачай Python 3.12 с python.org (Windows installer 64-bit),
при установке поставь галочку "Add Python to PATH".

ШАГ 3. ПАПКА ПРОЕКТА
Распакуй doe-hack.zip, например в C:\hack.
Открой папку doe-hack (в ней README.md и train.py),
набери в адресной строке проводника cmd и нажми Enter.

ШАГ 4. ОКРУЖЕНИЕ И БИБЛИОТЕКИ
    py -3.12 -m venv .venv
    .venv\Scripts\activate
    python -m pip install --upgrade pip
    pip install -r requirements.txt
В начале строки появится (.venv).
В КАЖДОМ НОВОМ ТЕРМИНАЛЕ: перейди в папку doe-hack и выполни .venv\Scripts\activate

ШАГ 5. PYTORCH ПОД RTX 3050
    pip install torch --index-url https://download.pytorch.org/whl/cu128
Весит около 2,8 ГБ - это нормально. Не закрывай терминал, пока качается.

ШАГ 6. САМОПРОВЕРКА
    python selftest.py
Должно быть:
    Устройство: cuda (NVIDIA GeForce RTX 3050 ...)
    все строки OK, в конце "ВСЁ РАБОТАЕТ"
Если в строке "Устройство" стоит cpu - поставился не тот PyTorch:
    pip uninstall -y torch
    pip install torch --index-url https://download.pytorch.org/whl/cu128

ШАГ 7. ОБУЧЕНИЕ (СВОЯ ВЕРСИЯ, ЗЕРНО 1)
    python train.py --steps 20000 --seed 1
- Сначала один раз генерируются 20 000 обучающих картинок (около 20-40 секунд).
- Каждые 100 шагов - ошибка. Должна в целом уменьшаться.
- Каждые 1000 шагов - "проверка: КК ... SSIM ...". Цифры должны расти.
  Лучшая модель сохраняется сама в checkpoints\best.pt ("<- лучшая, сохранена").
- СРАЗУ ПРИШЛИ ТИХОНУ строки "шаг 100", "шаг 200", "шаг 300" и первую "проверку".
  По ним посчитаем, сколько шагов успеешь до утра.
Загрузку видеокарты можно смотреть в другом окне: nvidia-smi

ЕСЛИ ОШИБКА "out of memory" (не хватает памяти видеокарты):
    python train.py --steps 20000 --seed 1 --batch 8
НЕ ЗАПУСКАЙ --base 48 - для 3050 слишком тяжело.

ШАГ 8. НА НОЧЬ
- Отключи сон: Параметры -> Система -> Питание -> "Переводить в спящий режим" = Никогда.
  Ноутбук - на зарядке.
- Продолжить и удлинить обучение (то же зерно):
    python train.py --steps 40000 --seed 1 --resume
  --resume продолжает с последней точки. Ctrl+C останавливает, лучшая модель уже сохранена.

ШАГ 9. ОТПРАВЬ МОДЕЛЬ ТИХОНУ
Файл checkpoints\best.pt - переименуй в best_radomir.pt и пришли утром.

ШАГ 10. ПРОВЕРЬ РЕЗУЛЬТАТ
    python solve.py --dir examples
    python benchmark.py --sets 20
- solve.py создаёт папку results\...: в final - файлы для сдачи, summary.png - картинка результата.
- benchmark.py сравнивает нейросеть с классикой: benchmark.png и benchmark.csv - пришли Тихону.

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
Пришли вывод терминала целиком (текстом или скриншотом). Не исправляй код наугад.

ЧТО ПОНИМАТЬ ДЛЯ ЗАЩИТЫ (ТЕБЯ СПРОСЯТ)
1. Как сеть учится без правильных ответов: сеть предлагает маску -> физика Френеля восстанавливает
   4 картинки -> ошибка считается прямо по метрикам кейса (1 - КК) + (1 - ИСС) -> ошибка идёт назад
   через физику в сеть. Учитель - физика.
2. Почему U-Net: похожий подход - DeepCGH (Eybposh et al., Optics Express, 2020), голограммы для
   нескольких плоскостей. На вход - 4 картинки + координаты пикселя (квадратичная фаза Френеля
   зависит от положения).
3. Почему ошибка в квадрате по плоскостям: сеть сильнее подтягивает худшую картинку, качество ровное.
4. Доводка: после сети - сотни шагов градиента по той же физике. Быстрее и лучше, чем
   Гершберг-Сакстон с нуля.
5. Почему трудно: плоскости всего в 1,2 мм друг от друга - картинки соседних плоскостей
   просвечивают друг в друга. Это предел для всех команд.
